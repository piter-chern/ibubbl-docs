### Retrieve a call

**Method:** `GET` | **Endpoint:** `/v1/calls/{call_id}`

**Description:** Fetch one of your calls by ID: the same object as in [List calls](/api-reference/calls/list) and in the [`call.*` webhooks](/webhooks/events#call-completed). Use it to read a call's current state, for example its voicemail transcription after `call.voicemail_transcribed`.

**Authentication:** API key in the `Authorization` header: `Authorization: Bearer ib_pk_<64 hex>`. Create keys in the dashboard under **Settings → API access**.

#### Request Body
None. The path parameter `call_id` is the call's ID (a UUID), from [List calls](/api-reference/calls/list) or a webhook's `data.id`.

<RequestExample>

```bash cURL
curl https://api.ibubbl.com/v1/calls/a41c7e2d-9b3f-4d61-8e5a-0c2b4d6f8a1e \
  -H "Authorization: Bearer $IBUBBL_API_KEY"
```

```typescript TypeScript
const callId = "a41c7e2d-9b3f-4d61-8e5a-0c2b4d6f8a1e";

const res = await fetch(`https://api.ibubbl.com/v1/calls/${callId}`, {
  headers: { Authorization: `Bearer ${process.env.IBUBBL_API_KEY}` },
  signal: AbortSignal.timeout(10_000),
});

const call = await res.json();
if (!res.ok) throw new Error(`${res.status} ${call.detail?.error}`);
console.log(call.status, call.duration_seconds, call.external_user_id);
```

```python Python
import os

import requests

API_KEY = os.environ["IBUBBL_API_KEY"]

call_id = "a41c7e2d-9b3f-4d61-8e5a-0c2b4d6f8a1e"

res = requests.get(
    f"https://api.ibubbl.com/v1/calls/{call_id}",
    headers={"Authorization": f"Bearer {API_KEY}"},
    timeout=10,
)
call = res.json()
if not res.ok:
    raise RuntimeError(f"{res.status_code} {call['detail']['error']}")
print(call["status"], call["duration_seconds"], call["external_user_id"])
```

#### Responses
**200 OK**

The call. Its fields are described on [List calls](/api-reference/calls/list#responses).

**401 Unauthorized**
```json
{
  "detail": {
    "error": "unauthorized",
    "message": "Invalid or revoked API key"
  }
}
```
Other `message` values: `Authorization Bearer token required`, `API key required (use Authorization: Bearer ib_pk_…)`, `Invalid API key format`, `Customer account not found`.

**403 Forbidden**
```json
{
  "detail": {
    "error": "forbidden",
    "message": "Account is suspended"
  }
}
```
Your iBubbl account is suspended or cancelled (`message` is then `Account is cancelled`). Every API-key endpoint returns this.

**404 Not Found**

`not_found`: no call with that ID on your account. A malformed ID and another account's call are answered the same way.
