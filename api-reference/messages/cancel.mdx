### Cancel a message

**Method:** `POST` | **Endpoint:** `/v1/messages/{message_id}/cancel`

**Description:** Stop a message you sent before your line picks it up: any `pending` message, including one held for the contact's [sending hours](/concepts/working-hours) or the line's hourly limit for new contacts (see `held_reason`), or one queued by a capacity hold (`status: "queued"`). It will never be sent. See [Edit, Undo Send and Cancel](/guides/editing-and-unsending#cancel-a-message-before-it-goes-out).

**Authentication:** API key in the `Authorization` header: `Authorization: Bearer ib_pk_<64 hex>`. Create keys in the dashboard under **Settings → API access**.

**Rate limit:** 300 conversation actions per 60 seconds per account (edits, unsends, cancels, tapbacks, mark read and typing together, across all your API keys). Over that, you get `429 rate_limited` with a `Retry-After` header; see [Rate limits](/concepts/limits#rate-limits).

#### Request Body

None. The path parameter `message_id` is the `id` from [Send a message](/api-reference/messages/send), or from [List messages](/api-reference/messages/list), where messages sent from the dashboard and by automations appear too.

#### How it behaves

- **It's immediate.** The answer is `200` with `status: "cancelled"`, and [`message.cancelled`](/webhooks/events#message-cancelled) fires. The message stays in the conversation history as cancelled; the contact never sees it.
- **It's safe to call twice.** Cancelling a cancelled message answers `200` with it, and no second `message.cancelled` fires.
- **Only while it's waiting.** A message already `sent`, `delivered`, `read`, `failed` or `expired`, or one you received, gets `422 not_cancellable`. To take back a message that already went out, [unsend it](/api-reference/messages/unsend) within 110 seconds.
- **Not once your line has picked it up.** In the second or so before a waiting message goes out, your line takes it to send; from then on, cancelling gets `409 message_dispatching`, and the message is sent (`message.sent` fires).
- **Retrying the send doesn't bring it back.** `POST /v1/messages` again with the same `idempotency_key` returns this cancelled message and sends nothing. To send it after all, use a new key.
- **Any channel.** It works whether the message would have gone out by iMessage or SMS, one-to-one or to a group.

```python Python
import os
import urllib.parse

import requests

API_KEY = os.environ["IBUBBL_API_KEY"]

message_id = "8b3a4e72-1c2d-4e5f-9a0b-2c3d4e5f6a7b"

res = requests.post(
    f"https://api.ibubbl.com/v1/messages/{urllib.parse.quote(message_id, safe='')}/cancel",
    headers={"Authorization": f"Bearer {API_KEY}"},
    timeout=10,
)
data = res.json()
if not res.ok:
    raise RuntimeError(f"{res.status_code} {data['detail']['error']}")
print(data["status"])  # "cancelled"
```

#### Responses
**200 OK**

The [message](/api-reference/messages/retrieve), now `cancelled` (or already cancelled). `held_until` and `held_reason` are `null`, and `channel` stays `null`: it never went out.

**401 Unauthorized**
```json
{
  "detail": {
    "error": "unauthorized",
    "message": "Invalid or revoked API key"
  }
}
```
Other `message` values: `Authorization Bearer token required`, `API key required (use Authorization: Bearer ib_pk_…)`, `Invalid API key format`, `Customer account not found`.

**403 Forbidden**
```json
{
  "detail": {
    "error": "forbidden",
    "message": "Account is suspended"
  }
}
```
Your iBubbl account is suspended or cancelled (`message` is then `Account is cancelled`). Every API-key endpoint returns this.

**404 Not Found**
```json
{
  "detail": {
    "error": "not_found",
    "message": "Message not found"
  }
}
```
Also returned for a malformed ID and a message that belongs to another account.

**409 Conflict**

`message_dispatching`: your line already has the message and will send it. Nothing changed; `message.sent` follows.

**422 Unprocessable Entity**
```json
{
  "detail": {
    "error": "not_cancellable",
    "message": "Only a message of yours that is still waiting to go out can be cancelled."
  }
}
```
`not_cancellable`: the message isn't one of yours that is still waiting to go out. It was sent, failed or expired, it's a message you received, or it's a meeting invite. Nothing changed.

**429 Too Many Requests**
```json
{
  "detail": {
    "error": "rate_limited",
    "message": "Too many conversation actions; wait 12s (limit 300 a minute per account)."
  }
}
```
Wait the `Retry-After` header's seconds, then send the same request again.
