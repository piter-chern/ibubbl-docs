### Retrieve a message

**Method:** `GET` | **Endpoint:** `/v1/messages/{message_id}`

**Description:** Fetch one message by its ID to check its delivery state. Use it when you can't receive webhooks.

**Authentication:** API key in the `Authorization` header: `Authorization: Bearer ib_pk_<64 hex>`. Create keys in the dashboard under **Settings → API access**.

#### Request Body
None. The path parameter `message_id` is the message's ID (a UUID), from the send response or a webhook event.

#### Example Request
```bash
curl https://api.ibubbl.com/v1/messages/8b3a4e72-1c2d-4e5f-9a0b-2c3d4e5f6a7b \
  -H "Authorization: Bearer $IB_API_KEY"
```

#### Responses
**200 OK**
```json
{
  "id": "8b3a4e72-1c2d-4e5f-9a0b-2c3d4e5f6a7b",
  "status": "delivered",
  "to": "+14155551234",
  "body": "Hey Sam — quick check-in about your order.",
  "contact_id": "c8a1f4e2-3b9d-4f7c-a8e5-1d2c3b4a5e6f",
  "conversation_id": "3a4b5c6d-7e8f-9a0b-1c2d-3e4f5a6b7c8d",
  "conversation_kind": "one_to_one",
  "chat_guid": null,
  "channel": "imessage",
  "sent_at": "2026-11-05T15:04:12.381Z",
  "held_until": null,
  "held_reason": null
}
```
`status` is one of `queued`, `pending`, `sent`, `delivered`, `read`, `failed`, `expired`, `cancelled`. `channel` is how it went out (`imessage` or `sms`), or `null` before it is sent.

**401 Unauthorized**
```json
{
  "detail": {
    "error": "unauthorized",
    "message": "Invalid or revoked API key"
  }
}
```
Other `message` values: `Authorization Bearer token required`, `API key required (use Authorization: Bearer ib_pk_…)`, `Invalid API key format`, `Customer account not found`.

**403 Forbidden**
```json
{
  "detail": {
    "error": "forbidden",
    "message": "Account is suspended"
  }
}
```
Your iBubbl account is suspended or cancelled (`message` is then `Account is cancelled`). Every API-key endpoint returns this.

**404 Not Found**
```json
{
  "detail": {
    "error": "not_found",
    "message": "Message not found"
  }
}
```
Also returned for a malformed ID and for a message that belongs to another account.
