### Retrieve a line

**Method:** `GET` | **Endpoint:** `/v1/lines/{line_id}`

**Description:** Fetch one of your lines by its ID, with today's usage against its send limits. Use it to look up the `line_id` on a message or a webhook.

**Authentication:** API key in the `Authorization` header: `Authorization: Bearer ib_pk_<64 hex>`. Create keys in the dashboard under **Settings → API access**.

#### Request Body
None. The path parameter `line_id` is the line's ID (a UUID), from [List lines](/api-reference/lines/list), or `line_id` on a message or a `message.*` webhook.

<RequestExample>

```bash cURL
curl https://api.ibubbl.com/v1/lines/5f0c2a9e-7d41-4b8a-9e3c-6a1b2c3d4e5f \
  -H "Authorization: Bearer $IBUBBL_API_KEY"
```

```typescript TypeScript
const lineId = "5f0c2a9e-7d41-4b8a-9e3c-6a1b2c3d4e5f";

const res = await fetch(`https://api.ibubbl.com/v1/lines/${lineId}`, {
  headers: { Authorization: `Bearer ${process.env.IBUBBL_API_KEY}` },
  signal: AbortSignal.timeout(10_000),
});

const data = await res.json();
if (!res.ok) throw new Error(`${res.status} ${data.detail?.error}`);
console.log(data.phone_number, data.status, data.limits?.messages_today);
```

```python Python
import os

import requests

API_KEY = os.environ["IBUBBL_API_KEY"]

line_id = "5f0c2a9e-7d41-4b8a-9e3c-6a1b2c3d4e5f"

res = requests.get(
    f"https://api.ibubbl.com/v1/lines/{line_id}",
    headers={"Authorization": f"Bearer {API_KEY}"},
    timeout=10,
)
data = res.json()
if not res.ok:
    raise RuntimeError(f"{res.status_code} {data['detail']['error']}")
print(data["phone_number"], data["status"], data["limits"] and data["limits"]["messages_today"])
```

#### Responses
**200 OK**

The line, in the same shape as an item of [List lines](/api-reference/lines/list#responses), where every field is described. The example above is a line at its daily new-contact limit, with its hour also full: 4 messages to new contacts wait for a slot, and the next one frees at `next_slot_at`.

**401 Unauthorized**
```json
{
  "detail": {
    "error": "unauthorized",
    "message": "Invalid or revoked API key"
  }
}
```
Other `message` values: `Authorization Bearer token required`, `API key required (use Authorization: Bearer ib_pk_…)`, `Invalid API key format`, `Customer account not found`.

**403 Forbidden**
```json
{
  "detail": {
    "error": "forbidden",
    "message": "Account is suspended"
  }
}
```
Your iBubbl account is suspended or cancelled (`message` is then `Account is cancelled`). Every API-key endpoint returns this.

**404 Not Found**
```json
{
  "detail": {
    "error": "line_not_found",
    "message": "No line with that id on this account."
  }
}
```
Also returned for a malformed ID and for a line that belongs to another account.

**503 Service Unavailable**
```json
{
  "detail": {
    "error": "limits_unavailable",
    "message": "Couldn't read this line's limits right now. Try again shortly."
  }
}
```
The line's live counters couldn't be read. Nothing is wrong with the line, and sends are unaffected. Retry after a few seconds.
