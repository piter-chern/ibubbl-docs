### Retrieve a contact

**Method:** `GET` | **Endpoint:** `/v1/contacts/{contact_id}`

**Description:** Fetch one contact by its ID, including whether it has opted out.

**Authentication:** API key in the `Authorization` header: `Authorization: Bearer ib_pk_<64 hex>`. Create keys in the dashboard under **Settings → API access**.

#### Request Body
None. The path parameter `contact_id` is the contact's ID (a UUID), from Create or update a contact, a send response, or a webhook event.

#### Example Request
```bash
curl https://web-production-4e09a.up.railway.app/v1/contacts/c8a1f4e2-3b9d-4f7c-a8e5-1d2c3b4a5e6f \
  -H "Authorization: Bearer $IB_API_KEY"
```

#### Responses
**200 OK**
```json
{
  "id": "c8a1f4e2-3b9d-4f7c-a8e5-1d2c3b4a5e6f",
  "phone": "+14155551234",
  "first_name": "Sam",
  "last_name": "Rivera",
  "timezone": "America/Los_Angeles",
  "opted_out": false,
  "opted_out_at": null,
  "created_at": "2026-11-05T14:23:45.123Z"
}
```
When `opted_out` is `true`, every send to this contact returns `422 contact_opted_out`.

**401 Unauthorized**
```json
{
  "detail": {
    "error": "unauthorized",
    "message": "Invalid or revoked API key"
  }
}
```
Other `message` values: `Authorization Bearer token required`, `API key required (use Authorization: Bearer ib_pk_…)`, `Invalid API key format`, `Customer account not found`.

**403 Forbidden**
```json
{
  "detail": {
    "error": "forbidden",
    "message": "Account is suspended"
  }
}
```
Your iBubbl account is suspended or cancelled (`message` is then `Account is cancelled`). Every API-key endpoint returns this.

**404 Not Found**
```json
{
  "detail": {
    "error": "not_found",
    "message": "Contact not found"
  }
}
```
Also returned for a malformed ID, a deleted contact, and a contact that belongs to another account.
