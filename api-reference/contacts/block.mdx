### Block a contact

**Method:** `POST` | **Endpoint:** `/v1/contacts/{contact_id}/block`

**Description:** Stop one-to-one messages to a contact until you [unblock](/api-reference/contacts/unblock) them. A block is your choice and can be undone; an [opt-out](/api-reference/contacts/opt-out) is the contact's and can't. See [Block or opt out](/concepts/suppression#block-or-opt-out).

**Authentication:** API key in the `Authorization` header: `Authorization: Bearer ib_pk_<64 hex>`. Create keys in the dashboard under **Settings → API access**.

#### Request Body
None. The path parameter `contact_id` is the contact's ID (a UUID).

#### What a block does

- **Sends are refused.** One-to-one sends to the contact, from the API, the dashboard or an automation, return `422 contact_blocked`. Group conversations they're in are not affected.
- **Their messages still arrive.** Inbound messages from them are stored and still fire [`message.inbound`](/webhooks/events), but they don't mark the conversation unread, notify your team, or start workflows.
- **No webhook fires**, for the block or the unblock.
- **It's safe to call twice.** Blocking a blocked contact answers `200` and keeps the original `blocked_at`.
- **It belongs to this contact.** If the contact is [deleted](/api-reference/contacts/delete) and the number later comes back as a new contact, the new one isn't blocked.

<RequestExample>

```bash cURL
curl -X POST https://api.ibubbl.com/v1/contacts/c8a1f4e2-3b9d-4f7c-a8e5-1d2c3b4a5e6f/block \
  -H "Authorization: Bearer $IBUBBL_API_KEY"
```

```typescript TypeScript
const contactId = "c8a1f4e2-3b9d-4f7c-a8e5-1d2c3b4a5e6f";

const res = await fetch(`https://api.ibubbl.com/v1/contacts/${contactId}/block`, {
  method: "POST",
  headers: { Authorization: `Bearer ${process.env.IBUBBL_API_KEY}` },
  signal: AbortSignal.timeout(10_000),
});

const data = await res.json();
if (!res.ok) throw new Error(`${res.status} ${data.detail?.error}`);
console.log(data.blocked, data.blocked_at);
```

```python Python
import os

import requests

API_KEY = os.environ["IBUBBL_API_KEY"]

contact_id = "c8a1f4e2-3b9d-4f7c-a8e5-1d2c3b4a5e6f"

res = requests.post(
    f"https://api.ibubbl.com/v1/contacts/{contact_id}/block",
    headers={"Authorization": f"Bearer {API_KEY}"},
    timeout=10,
)
data = res.json()
if not res.ok:
    raise RuntimeError(f"{res.status_code} {data['detail']['error']}")
print(data["blocked"], data["blocked_at"])
```


**401 Unauthorized**
```json
{
  "detail": {
    "error": "unauthorized",
    "message": "Invalid or revoked API key"
  }
}
```
Other `message` values: `Authorization Bearer token required`, `API key required (use Authorization: Bearer ib_pk_…)`, `Invalid API key format`, `Customer account not found`.

**403 Forbidden**
```json
{
  "detail": {
    "error": "forbidden",
    "message": "Account is suspended"
  }
}
```
Your iBubbl account is suspended or cancelled (`message` is then `Account is cancelled`). Every API-key endpoint returns this.

**404 Not Found**
```json
{
  "detail": {
    "error": "not_found",
    "message": "Contact not found"
  }
}
```
Also returned for a malformed ID, a deleted contact, and a contact that belongs to another account.
