### Create or update a contact

**Method:** `POST` | **Endpoint:** `/v1/contacts`

**Description:** Create a contact, or match an existing one, by phone number. On an existing contact the optional fields are only filled where they are still empty; values a rep or an earlier call set are never overwritten.

**Authentication:** API key in the `Authorization` header: `Authorization: Bearer ib_pk_<64 hex>`. Create keys in the dashboard under **Settings → API access**.

#### Request Body
| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `phone` | string (E.164, e.g. `+14155551234`) | Yes | The contact's phone number, and the key it is matched on. Sending the same number again returns the same contact. |
| `first_name` | string, at most 128 characters | No | Only applied if the contact has no first name yet. |
| `last_name` | string, at most 128 characters | No | Only applied if the contact has no last name yet. |
| `timezone` | string | No | IANA zone used for the contact's sending hours. Must be one of 20 supported zones (the US, Canada and a few international ones, e.g. `Europe/London`). Only applied if the contact has no timezone yet, so set it on the first call, before you send. |

Fields not listed above are ignored without an error: the request still succeeds, and they are not stored. There is no API endpoint yet to update, list or delete contacts.

#### Example Request
```bash
curl -X POST https://web-production-4e09a.up.railway.app/v1/contacts \
  -H "Authorization: Bearer $IB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "+14155551234",
    "first_name": "Sam",
    "last_name": "Rivera",
    "timezone": "America/Los_Angeles"
  }'
```

#### Responses
**201 Created**
```json
{
  "id": "c8a1f4e2-3b9d-4f7c-a8e5-1d2c3b4a5e6f",
  "phone": "+14155551234",
  "first_name": "Sam",
  "last_name": "Rivera",
  "timezone": "America/Los_Angeles",
  "opted_out": false,
  "opted_out_at": null,
  "created_at": "2026-11-05T14:23:45.123Z"
}
```
A new contact was created. A number whose only match is a deleted contact also creates a new one.

**200 OK**
```json
{
  "id": "c8a1f4e2-3b9d-4f7c-a8e5-1d2c3b4a5e6f",
  "phone": "+14155551234",
  "first_name": "Sam",
  "last_name": "Rivera",
  "timezone": "America/Los_Angeles",
  "opted_out": false,
  "opted_out_at": null,
  "created_at": "2026-11-05T14:23:45.123Z"
}
```
The number matched an existing contact; empty fields were filled from the request.

**401 Unauthorized**
```json
{
  "detail": {
    "error": "unauthorized",
    "message": "Invalid or revoked API key"
  }
}
```
Other `message` values: `Authorization Bearer token required`, `API key required (use Authorization: Bearer ib_pk_…)`, `Invalid API key format`, `Customer account not found`.

**403 Forbidden**
```json
{
  "detail": {
    "error": "forbidden",
    "message": "Account is suspended"
  }
}
```
Your iBubbl account is suspended or cancelled (`message` is then `Account is cancelled`). Every API-key endpoint returns this.

**422 Unprocessable Entity**
```json
{
  "detail": {
    "error": "validation_error",
    "message": "phone must be E.164 format (e.g. +14155551234)"
  }
}
```
Other `error` value: `invalid_timezone`, for a `timezone` outside the supported list:
```json
{
  "detail": {
    "error": "invalid_timezone",
    "message": "timezone must be one of ['America/Anchorage', 'America/Chicago', 'America/Denver', 'America/Edmonton', 'America/Halifax', 'America/Los_Angeles', 'America/New_York', 'America/Phoenix', 'America/St_Johns', 'America/Toronto', 'America/Vancouver', 'America/Winnipeg', 'Asia/Singapore', 'Asia/Tokyo', 'Australia/Sydney', 'Europe/Berlin', 'Europe/London', 'Europe/Madrid', 'Europe/Paris', 'Pacific/Honolulu']; got 'Mars/Olympus'"
  }
}
```
