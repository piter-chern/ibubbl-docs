### Update a contact

**Method:** `PATCH` | **Endpoint:** `/v1/contacts/{contact_id}`

**Description:** Overwrite the fields you send. Fields you leave out are not touched, and a field sent as `null` is cleared. Unlike Create or update a contact, this replaces values a rep set.

**Authentication:** API key in the `Authorization` header: `Authorization: Bearer ib_pk_<64 hex>`. Create keys in the dashboard under **Settings → API access**.

#### Request Body
The path parameter `contact_id` is the contact's ID (a UUID). Send at least one field; an empty body changes nothing and returns the contact.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `first_name` | string or `null`, at most 128 characters | No | New first name; `null` clears it. |
| `last_name` | string or `null`, at most 128 characters | No | New last name; `null` clears it. |
| `email` | string or `null`, at most 254 characters | No | Must look like an email address, or `422 invalid_email`; `null` clears it. |
| `city` | string or `null`, at most 128 characters | No | Trimmed; blank or `null` clears it. |
| `state` | string or `null`, at most 128 characters | No | Trimmed, a 2-letter code upper-cased; blank or `null` clears it. |
| `timezone` | string or `null` | No | Any real IANA zone, or `422 invalid_timezone`. `null` makes it automatic again: iBubbl infers the zone from the phone number. |

Fields not listed above are rejected with `422 validation_error`, and the message names the field. `phone` can't be changed (a new contact's number is checked when it's created; see [Create or update a contact](/api-reference/contacts/upsert)), and tags have their own endpoints: [Add a tag](/api-reference/contacts/add-tag) and [Remove a tag](/api-reference/contacts/remove-tag).

<RequestExample>

```bash cURL
curl -X PATCH https://api.ibubbl.com/v1/contacts/c8a1f4e2-3b9d-4f7c-a8e5-1d2c3b4a5e6f \
  -H "Authorization: Bearer $IBUBBL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "first_name": "Sam",
    "email": "sam.rivera@example.com",
    "city": null
  }'
```

```typescript TypeScript
const contactId = "c8a1f4e2-3b9d-4f7c-a8e5-1d2c3b4a5e6f";

const res = await fetch(`https://api.ibubbl.com/v1/contacts/${contactId}`, {
  method: "PATCH",
  headers: {
    Authorization: `Bearer ${process.env.IBUBBL_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    first_name: "Sam",
    email: "sam.rivera@example.com",
    city: null, // null clears the field
  }),
  signal: AbortSignal.timeout(10_000),
});

const data = await res.json();
if (!res.ok) throw new Error(`${res.status} ${data.detail?.error}`);
console.log(data.first_name, data.email, data.city);
```

```python Python
import os

import requests

API_KEY = os.environ["IBUBBL_API_KEY"]

contact_id = "c8a1f4e2-3b9d-4f7c-a8e5-1d2c3b4a5e6f"

res = requests.patch(
    f"https://api.ibubbl.com/v1/contacts/{contact_id}",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "first_name": "Sam",
        "email": "sam.rivera@example.com",
        "city": None,  # None (JSON null) clears the field
    },
    timeout=10,
)
data = res.json()
if not res.ok:
    raise RuntimeError(f"{res.status_code} {data['detail']['error']}")
print(data["first_name"], data["email"], data["city"])
```

#### Responses
**200 OK**
```json
{
  "id": "c8a1f4e2-3b9d-4f7c-a8e5-1d2c3b4a5e6f",
  "phone": "+14155551234",
  "first_name": "Sam",
  "last_name": "Rivera",
  "email": "sam.rivera@example.com",
  "city": null,
  "state": "NY",
  "timezone": "America/New_York",
  "tags": [
    "VIP"
  ],
  "opted_out": false,
  "opted_out_at": null,
  "blocked": false,
  "blocked_at": null,
  "created_at": "2026-11-05T14:23:45.123Z"
}
```
`first_name` and `email` were replaced, `city` was cleared, and every other field kept its value.

**401 Unauthorized**
```json
{
  "detail": {
    "error": "unauthorized",
    "message": "Invalid or revoked API key"
  }
}
```
Other `message` values: `Authorization Bearer token required`, `API key required (use Authorization: Bearer ib_pk_…)`, `Invalid API key format`, `Customer account not found`.

**403 Forbidden**
```json
{
  "detail": {
    "error": "forbidden",
    "message": "Account is suspended"
  }
}
```
Your iBubbl account is suspended or cancelled (`message` is then `Account is cancelled`). Every API-key endpoint returns this.

**404 Not Found**
```json
{
  "detail": {
    "error": "not_found",
    "message": "Contact not found"
  }
}
```
Also returned for a malformed ID, a deleted contact, and a contact that belongs to another account.

**422 Unprocessable Entity**
```json
{
  "detail": {
    "error": "validation_error",
    "message": "phone: Extra inputs are not permitted"
  }
}
```
Other `error` values: `validation_error` for any other unknown field (including `tags`) or a value too long; `invalid_email` (`'sam' is not an email address`); `invalid_timezone`.
