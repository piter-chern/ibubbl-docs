### Revoke a webhook subscription

**Method:** `DELETE` | **Endpoint:** `/v1/webhooks/{subscription_id}`

**Description:** Stop sending events to a subscription. Revoking twice is safe.

**Authentication:** API key in the `Authorization` header: `Authorization: Bearer ib_pk_<64 hex>`. Create keys in the dashboard under **Settings → API access**.

#### Request Body
None. The path parameter `subscription_id` is the subscription's ID (a UUID).

<RequestExample>

```bash cURL
curl -X DELETE https://api.ibubbl.com/v1/webhooks/4a5b6c7d-8e9f-0a1b-2c3d-4e5f6a7b8c9d \
  -H "Authorization: Bearer $IBUBBL_API_KEY"
```

```typescript TypeScript
const subscriptionId = "4a5b6c7d-8e9f-0a1b-2c3d-4e5f6a7b8c9d";

const res = await fetch(`https://api.ibubbl.com/v1/webhooks/${subscriptionId}`, {
  method: "DELETE",
  headers: { Authorization: `Bearer ${process.env.IBUBBL_API_KEY}` },
  signal: AbortSignal.timeout(10_000),
});

const data = await res.json();
if (!res.ok) throw new Error(`${res.status} ${data.detail?.error}`);
console.log(data.status); // "revoked" or "already_revoked"
```

```python Python
import os

import requests

API_KEY = os.environ["IBUBBL_API_KEY"]

subscription_id = "4a5b6c7d-8e9f-0a1b-2c3d-4e5f6a7b8c9d"

res = requests.delete(
    f"https://api.ibubbl.com/v1/webhooks/{subscription_id}",
    headers={"Authorization": f"Bearer {API_KEY}"},
    timeout=10,
)
data = res.json()
if not res.ok:
    raise RuntimeError(f"{res.status_code} {data['detail']['error']}")
print(data["status"])  # "revoked" or "already_revoked"
```

#### Responses
**200 OK**
```json
{
  "status": "revoked"
}
```
A subscription that was already revoked returns `{"status": "already_revoked"}`.

**401 Unauthorized**
```json
{
  "detail": {
    "error": "unauthorized",
    "message": "Invalid or revoked API key"
  }
}
```
Other `message` values: `Authorization Bearer token required`, `API key required (use Authorization: Bearer ib_pk_…)`, `Invalid API key format`, `Customer account not found`.

**403 Forbidden**
```json
{
  "detail": {
    "error": "forbidden",
    "message": "Account is suspended"
  }
}
```
Your iBubbl account is suspended or cancelled (`message` is then `Account is cancelled`). Every API-key endpoint returns this.

**404 Not Found**
```json
{
  "detail": {
    "error": "not_found",
    "message": "Webhook subscription not found"
  }
}
```
Also returned for a malformed ID and for a subscription that belongs to another account.
